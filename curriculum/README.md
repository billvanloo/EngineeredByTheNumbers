# Curriculum materials

- [`engineered-by-the-numbers.html`](engineered-by-the-numbers.html) is the unit plan for "Engineered by the Numbers", and the basis for the whole curriculum. It covers the modules, periods, required concepts, activities, worked checks, math and physics supplements, capstone rubric, safety summary and references. It also has six built-in interactives, which are the prototypes for the standalone tools. Open it in any browser.

The tool specifications are in `../engineered-by-the-numbers-tool-specs/`.
