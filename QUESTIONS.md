# Open questions

Decisions the specs leave open, formulas a tool needed that the spec doesn't give, and anything else for the teacher to confirm. Each entry says what the build did in the meantime, so nothing is blocked.

| # | Where | Question | What the build does for now |
|---|---|---|---|
| Q1 | 00 §1 | The small-screen rule says "show a notice … matching the Gear Train Workbench's current behavior." The Workbench has no on-screen notice today. It only says in help that phones are too small. | A dismissible banner appears below 768 px: "This tool needs a larger screen, at least 1024 px wide, for full use. The readouts still work here." The layout stays usable and readouts stay readable. |
| Q2 | 00 §2 | The Truss Stress Visualizer has only the light theme. The Gear Train Workbench has both light and blueprint. | The palette is copied from the Gear Train Workbench (both themes), with the same token names so the tools look alike. |
| Q3 | 01 §3.3 vs §4 | The default torque output station is "the heaviest load station" in §3.3, but "L/2" in the §4 table. These are the same for the default single load at L/2. | Output defaults to the heaviest load's station, or L/2 when there are no loads. After that it's whatever the student sets. |
| Q4 | 01 §4, 00 §9 | The Sy preset list must ship as placeholders for the teacher to replace. | Presets are "Placeholder steel (400 MPa)", "Placeholder aluminum (250 MPa)", "Placeholder brass (200 MPa)" and "Custom". Every one is flagged "placeholder value in use" in the readout. **Teacher to supply datasheet values.** |
| Q5 | 02 §5.5 | "Accept a drive-request … return a drive-result." Without a server, "return" has to be a file. | The Motor and Drive Matcher loads a `drive-request` JSON (Load menu, or dropped on the page) and offers "Export drive result" as a JSON download. The Workbench and Conveyor Designer will import that file. |
| Q6 | 02 §5.1 | The teacher-editable motor list is "JSON in settings." | The settings dialog has a text area holding the list as JSON, which is validated and saved in local storage. To share the list with a class, the teacher copies the JSON out of the text area and students paste it into theirs. |
| Q7 | 02 mockup | The mockup header shows a Sandbox/Challenge switch, but spec 02 defines no challenges (and neither does spec 01). | Tools 01 and 02 run in sandbox mode only, and predict-first works there. Prediction records use `sandbox-<hash of inputs>` as the problem ID. **Teacher to supply** a challenge list if one is wanted. The shell already supports a mode switch and a `problemId` hook. |
| Q8 | 02 §4 | Voltage, I₀ and I_s default to blank. The shared input fields need a number. | They sit behind the "Show current and efficiency" extension switch, which is off by default, and start at the MD-5 example values (12 V, 0.2 A, 10 A) with the note "The starting values are examples." |
| Q9 | 02 §5.4 | "Add motor to compare" doesn't say whether a compared motor can have several motors in parallel. | Compared motors are single motors (stall torque and no-load speed) sharing the main gearing and load. |
| Q10 | 00 §6 | Neither spec says whether the Report should reveal results that predict-first is hiding. | The report shows hidden values as "hidden until checked", so printing is not a way around predicting. |
| Q11 | 03 §5.3 | How fast should an overhauling load drop? The spec gives no inertia or drag for the screw. | Show a qualitative drop that speeds up, and say in help that the speed is for show and only "drops or holds" is computed. |
| Q12 | 03 §3.1 | Standard deviation of measured μ: sample (n − 1) or population? | Sample (n − 1), labelled "sample standard deviation". |
| Q13 | 03 §6 | "Self-locking yes or no" is a predict target, but the log's `predicted` is a number. | Log 1 for yes and 0 for no with unit `yes/no`, and a match only when equal. |
| Q14 | 03 §3.5 | Should the back-calculation include collar friction (solve for thread μ with μ_c fixed)? | Yes: T_R,total(μ) = F_meas·R with μ_c held. Same as the spec when μ_c = 0 (FS-9). |
| Q15 | 03 §4 | Which challenges ship? Only "mystery surface" is named. | Ship one example mystery-surface challenge and the challenge-list format, marked as an example for the teacher to replace. |
| Q16 | 04 §3.2 | With a negative offset a, "Energizing" no longer describes the physics. Should direction be clockwise or counterclockwise instead, with energizing worked out from the sign of a? | Implement the spec formulas as written with signed a, and show the self-energizing factor so the effect is visible. |
| Q17 | 04 §3.5 | Specific heat presets other than steel are "teacher-entered placeholders". Which ones? | Steel 452 (OpenStax) plus "Placeholder aluminum" and "Placeholder brass", flagged as placeholders. |
| Q18 | 04 §8 | The frame-counting student guide has no source text in the specs. | Draft it and mark it for teacher review. |
| Q19 | 05 §4 | "Motor power margin: available motor power at operating point" — at an operating point the motor delivers exactly what the load takes. Is "available" the motor's maximum power, T_s·ω₀/4? | Use maximum power T_s·ω₀/4 ÷ required motor power, and label the formula. **Needs review.** |
| Q20 | 05 CD-5 | One drive efficiency η is used for both "motor power needed" and the gearbox stage efficiency. Is that intended? | Yes, one field, as CD-5 does. |
| Q21 | 05 §4 | Requirement rows need a comparison (at least, at most, target ± tolerance); the spec gives only target and tolerance. | Add the comparison column, as the mockup implies. |
| Q22 | 05 §3.7 | Direction of the side load in the shaft-loads export. `schemas.md` shows 270° (down), but for 180° wrap both spans pull toward the tail. | Compute the direction from the span geometry (the bisector of the two spans) and note it in help. The Shaft and Beam Workbench result doesn't depend on it for one load. |
| Q23 | 06 | No predict-first targets are listed. | Computed lines are the targets (section 8.4 above). |
| Q24 | 06 §3.5 | `omega = 2*pi*N/60` with N in rpm is a numeric-value equation. Read strictly in SI, it gives the wrong value. | Recognise the rpm conversion pattern and use N's number in rpm, with a note. |
| Q25 | 06 §3.5 | How does the tool know a °C value is absolute or a difference? | Typed °C values are absolute unless the name starts with d, Δ or delta, or the value is a difference of two temperatures. °C inside compound units (J/(kg·°C)) is a difference. |
| Q26 | 07 §4 | The Collector mockup shows Predict first and Name in the header. | Hide both (teacher tool). |
| Q27 | 07 §4.1 | Records have no module field. Several tools serve more than one module. | Map tool to modules from the spec README, and narrow by challenge prefix when present. **Teacher may prefer a `module` field in schema version 2.** |
| Q28 | 07 §4.2 | Should loaded class data persist in local storage? | No. Memory only, cleared on reload, with a note in help. |
| Q29 | 07 PL-11 | A real Google Sheets round trip needs a Google account. | Use a synthetic Sheets-style fixture, and ask the teacher for one real re-saved file. |
| Q30 | 05 §3.5 | "Build this in the Gear Train Workbench" can't work until spec 08 is built. | Export the drive-request now and point to the Motor and Drive Matcher in help until Phase 8. |
| Q31 | 00 §6, 07 | A teacher tool (the Collector) has no Name field, so its file names start with `unnamed_` (for example `unnamed_prediction-log-collector_sandbox_2026-11-01.csv`). | Kept as `unnamed` for now so every tool follows one file-name rule. Could become the class period or `class`. |
| Q32 | 03 §3.4 | τ = 16 T_R / (π d_r³): with a collar, should T_R be the thread torque or the total including the collar? FS-4 has no collar, so it doesn't decide. | The thread torque T_R (the collar torque is reacted at the collar, not carried through the threaded root). The help panel's teacher notes say so. **Teacher to confirm.** |
